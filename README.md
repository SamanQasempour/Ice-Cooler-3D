## 📖 Overview

This project is an **interactive 3D model** of a homemade ice cooler created using **Three.js**.

The visualization demonstrates how cold air flows through a PVC pipe while an exhaust fan pushes air across an ice container, producing cool air at the outlet.

The project is designed for educational purposes, engineering demonstrations, and interactive presentations.

---

## ✨ Features

- 🎮 Interactive 3D Camera Controls
- ❄️ Transparent Ice Container
- 🌬️ Animated Hot & Cold Air Particles
- 🌀 Rotating Exhaust Fan
- 💧 Water Drain Visualization
- 💡 Realistic Lighting & Shadows
- 📱 Responsive Design
- 🏷️ Component Labels
- 🔍 Zoom, Rotate & Pan Controls
- 🌫️ Atmospheric Fog Effects

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript (ES6)
- Three.js r128

## 📦 Components

The model includes:

- Styrofoam Box
- PVC Pipe (Ø10 cm)
- Ice Container
- Water Drain
- Exhaust Fan
- Hot Air Intake
- Cold Air Outlet

## 🚀 Getting Started

Clone the repository

```bash
git clone https://github.com/yourusername/diy-ice-cooler.git
```

Open the project

```bash
cd diy-ice-cooler
```

Simply open:

```
index.html
```

or run a local server:

```bash
python -m http.server
```

Then visit

```
http://localhost:8000
```
